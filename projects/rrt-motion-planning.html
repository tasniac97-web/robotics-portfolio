ROBOTICS / MOTION PLANNING

RRT Motion Planning & Obstacle Avoidance

Developed a Rapidly-exploring Random Tree (RRT) motion planning algorithm in ROS and Python to generate and execute collision-free paths for a simulated KUKA robotic arm navigating around obstacles.

Project Overview

This project was completed at Columbia University and focused on robotic motion planning and obstacle avoidance.

I implemented a Rapidly-exploring Random Tree (RRT) algorithm using Python and ROS to plan and execute robot arm trajectories in an environment containing obstacles.

Inverse kinematics was used to determine the goal configuration in joint space, enabling the KUKA robotic arm to move toward its target configuration.

Technical Approach

The motion planning process used RRT to explore possible robot configurations and generate paths around obstacles.

Inverse kinematics was applied to obtain the desired goal configuration in joint space. The planning algorithm then generated a path toward that configuration.

The planned motion was executed in a simulated environment containing a KUKA robotic arm and surrounding obstacles.
