ROBOTICS / MOTION PLANNING

RRT Motion Planning & Obstacle Avoidance

Developed a Rapidly-exploring Random Tree (RRT) motion planning algorithm in ROS and Python to generate and execute collision-free paths for a simulated KUKA robotic arm navigating around obstacles.

Rapidly-exploring Random Tree (RRT)

Rapidly-exploring Random Tree (RRT) is a sampling-based motion planning algorithm used to find feasible paths through complex environments.

Instead of searching every possible robot configuration, RRT incrementally builds a tree by randomly sampling configurations in the robot's configuration space. This makes it particularly useful for robotic manipulators with multiple degrees of freedom.

The algorithm starts at the robot's initial joint configuration and expands toward randomly sampled configurations. Each new connection is checked for collisions with obstacles.

The tree continues expanding until it reaches the desired goal configuration, producing a sequence of configurations that the robot can follow.

RRT Algorithm Steps

  1. Initialize: Start the tree at the robot's initial joint configuration.
  2. Random Sampling: Generate a random configuration within the robot's joint limits.
  3. Nearest Neighbor: Identify the closest existing node in the tree.
  4. Tree Expansion: Extend the tree from the nearest node toward the sampled configuration.
  5. Collision Checking: Validate that the new motion segment does not intersect obstacles.
  6. Goal Connection: Repeat the process until the tree reaches the goal region and a valid path can be reconstructed.

RRT is probabilistically complete under standard assumptions, meaning that if a feasible path exists, the probability of finding one approaches 1 as the number of samples increases. However, a basic RRT does not guarantee the shortest or optimal path.

ROS MoveIt Simulation

ROS (Robot Operating System) provides a software framework for robot control, communication, and motion planning. MoveIt is a ROS-based framework that supports robot kinematics, collision checking, trajectory planning, and execution.

A KUKA robotic arm can be represented in MoveIt using a robot model containing its joint definitions, kinematic structure, and collision geometry.

The simulation environment contains obstacles that the robot must navigate around while moving between configurations. Inverse kinematics converts a desired end-effector pose into a target joint-space configuration.

A motion planner then searches for a collision-free path between the initial and target configurations. The resulting trajectory can be visualized in RViz and executed in a simulated environment.

Technical Approach

I implemented an RRT motion planning algorithm in Python using ROS to generate paths for a simulated KUKA robotic arm.

Inverse kinematics was applied to obtain the desired goal configuration in joint space. The RRT algorithm then explored possible configurations to generate a path toward the target while avoiding obstacles.

The planned motion was executed in a simulated environment containing the KUKA robotic arm and surrounding obstacles.

Simulation Results

The robot arm was able to successfully avoid obstacles and reach its destination.
