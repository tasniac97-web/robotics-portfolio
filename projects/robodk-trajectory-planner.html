RoboDK Trajectory Planner

A Python-based application for planning robot trajectories, validating motion paths, and automating teachpoint and program generation in RoboDK.

Python RoboDK A* Search Trajectory Planning Inverse Kinematics Collision Checking Robot Programming Tkinter

Overview

The RoboDK Trajectory Planner is a Python-based desktop application developed to automate robotic trajectory planning and program generation within RoboDK.

The application uses existing pick-and-place teachpoints as inputs, generates candidate robot trajectories using graph-based path planning, and incorporates robot reachability and collision validation.

The tool also creates new teachpoints under the Robot Frame, generates robot motion programs, and automatically tests the resulting paths in RoboDK.

Key Features

Graph-Based Path Planning

Uses A* search over a free-space graph to generate candidate robot trajectories.

Robot Motion Validation

Incorporates inverse kinematics and collision checks to evaluate robot motion feasibility.

Automatic Teachpoint Creation

Generates new visible teachpoints under the Robot Frame based on the planned trajectories.

Automated Program Generation

Creates RoboDK motion programs and automatically tests the generated robot paths.

Application Workflow

  1. Open the RoboDK Station: Open the RoboDK file containing the robot model, reference frames, and target locations.
  2. Identify PNP Teachpoints: Add the desired pick-and-place targets with names ending in "PNP". Matching is case-insensitive.
  3. Generate Candidate Paths: The planning engine constructs a free-space graph and uses A* search to identify candidate routes.
  4. Validate Robot Motion: The application uses RoboDK robot kinematics and collision checking to evaluate candidate trajectories.
  5. Create Robot Programs: The tool generates new teachpoints under the Robot Frame and creates RoboDK motion programs.
  6. Test Generated Paths: The application automatically tests the generated robot paths in RoboDK.
System Integration: The application connects Python-based trajectory planning with RoboDK robot simulation and program generation.

A* Path Planning

The trajectory planning engine uses a graph-based approach to search for candidate robot motion paths.

A free-space graph represents possible connections between locations in the planning environment. A* search is used to find a route through the graph toward the desired target.

Planning Process

  1. Construct the Graph: Build a representation of candidate connections through free space.
  2. Search for a Path: Use the A* algorithm to evaluate possible routes between locations.
  3. Generate Alternatives: Explore additional candidate paths when evaluating different routes.
  4. Refine the Trajectory: Apply path-shortening logic to evaluate more direct motion paths.
Planning Approach: Graph-based search with A*, alternative-route generation, and trajectory refinement.

Reachability and Collision Validation

A geometric path alone does not guarantee that a physical robot can execute the required motion.

The application incorporates RoboDK inverse kinematics and collision checking to evaluate candidate paths against the robot model and simulation environment.

Validation Process

  1. Inverse Kinematics: Evaluate whether the robot can achieve the required target poses.
  2. Collision Checking: Check candidate robot motions against the configured simulation environment.
  3. Motion Feasibility: Evaluate candidate trajectory segments using RoboDK motion validation capabilities.
  4. Path Refinement: Evaluate possible shortcuts and alternative routes while accounting for robot motion constraints.
Engineering Consideration: Trajectory planning must account for both geometric routing and the robot's kinematic and collision constraints.

Automated RoboDK Program Generation

After trajectory planning, the application automates the creation of RoboDK targets and motion programs.

Teachpoint Naming Convention

Input teachpoints must have names ending in "PNP". Matching is case-insensitive.

Example input teachpoint names:
Pick_PNP
Place_PNP
Station1_pnp
Target2_PnP

Generated Outputs

  1. New Teachpoints: Creates additional robot targets based on the planned trajectory.
  2. Robot Frame Organization: Places generated teachpoints under the Robot Frame and makes them visible.
  3. Motion Programs: Generates new RoboDK programs using the planned targets.
  4. Automated Testing: Tests the generated robot path in the RoboDK environment.
Automation Objective: Reduce repetitive manual target creation, motion program setup, and simulation testing during robot trajectory development.

Desktop Application

The tool includes a Python Tkinter graphical user interface for interacting with the trajectory planning workflow.

The application provides controls for initiating trajectory planning, managing generated RoboDK objects, and viewing application logs.

Software Stack: Python, RoboDK API, Tkinter, graph-based search, robot kinematics, and simulation-based motion validation.
