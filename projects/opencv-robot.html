PROJECT 01 · COMPUTER VISION & ROBOTICS

OpenCV Robot Camera Perception

Developed a camera-based perception system using OpenCV to detect and locate a plate, calculate its position relative to the robot, and control the robot arm to move to and grip the object.

OpenCV Computer Vision Meca Robot Microcontroller Robot Control

Overview

This project explores how camera-based perception can guide a robotic arm to locate and grasp an object. OpenCV is used to detect the target plate in the camera image, and the detected position is used to guide the robot toward the object.

The project brings together computer vision, position estimation, robot motion, and hardware control to connect visual information with physical interaction.

Objective

Enable a robot arm to identify a plate using a camera and move to the plate's center to perform a grasp, rather than relying exclusively on a predefined target position.

System Architecture

Vision System

A camera captures the scene, and OpenCV processes the image to detect and locate the target plate.

Position Estimation

The detected target position is used to determine where the robot needs to move relative to the plate.

Robot Control

The position estimate guides the Meca robot arm toward the target for grasping.

Hardware Interface

A microcontroller is part of the hardware control setup connecting the project components.

Computer Vision

OpenCV provides the image-processing component of the system. The goal is to identify the plate in the camera image and determine its center so that the robot can use the detected target position.

The perception stage connects camera observations to the downstream positioning and grasping task.

Robot Positioning & Grasping

After locating the plate, the system uses its estimated position relative to the robot to guide arm movement toward the center of the target. The intended outcome is to position the robot for gripping the object.

This connects the perception output to a physical manipulation task, bringing together vision and robotic motion control.

Hardware & Software

Hardware

  • Meca robot arm
  • Camera
  • Microcontroller
  • Target plate and grasping setup

Software & Control

  • OpenCV
  • Image-based target detection
  • Position estimation
  • Robot motion and grasping

Outcome

The project demonstrates a vision-guided robotics workflow in which a camera identifies an object's location and that information is used to guide the robot arm toward a grasping position.

The result is an integrated perception-to-action approach that connects computer vision with physical robot manipulation.
